# E-Commerce Project 🛒

This is an **e-commerce project built with React, Vite, and Tailwind CSS**. It was created to practice modern frontend development, dynamic UI management, and essential online store concepts such as displaying products, page navigation, and responsive design.

---

## 🚀 Project Description

This project is a **basic online store** that implements product components, a shopping cart (UI only, still working on it), searchbar, page navigation, and a styled interface using Tailwind CSS. **Vite** is used as a bundler for a fast and efficient development environment.

---

## 📌 Main Features

- Product listing  
- Modern and responsive interface  
- Shopping cart (UI only)  
- Functional React components  
- Page routing/navigation  
- Tailwind CSS styling

> 💡 This project serves as an excellent base to develop and integrate real logic (backend, API, authentication, payments, etc.).

## 📥 Installation and Running

1. Clone the repository:

```bash
git clone https://github.com/estebanquinterob/ecommerce-project.git
```
2. Navigate into the project and install dependencies:

```bash
cd ecommerce-project
npm install
```

3. Start the local development server:

```bash
Copiar código
npm run dev
```
4. Open in your browser:

http://localhost:3000




# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
